# Dharanish R P — AI & Machine Learning Engineer

A portfolio about practical intelligence, local AI, computer vision, and the systems that connect models with people.

## Run locally

```powershell
npm ci
npm run dev
```

Open http://localhost:3000.

## Production build

```powershell
npm run build
npm run start
```

## Design

The homepage is a warm editorial studio centered on Dharanish's original cutout portrait. It includes a selected-project gallery, accessible project notes, interactive conceptual system studies, recognition, and direct contact links. See `review/DESIGN_NOTES.md` for visual direction, motion decisions, artwork provenance, and project-claim boundaries.

Project covers are illustrative concept artwork, not product screenshots. Smart Bin and Microplastic Detection are concepts; the document-intelligence project describes an exploration. No unverified performance claims are presented.

## Deployment

This Next.js App Router project builds with `next build` and is configured for Vercel. The GitHub `main` branch is intended as the production branch.
